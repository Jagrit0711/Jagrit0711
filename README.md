### [ai skill gap identifier for freelance readiness](https://github.com/Jagrit0711/AI-Based-Skill-Gap-Identification-for-Freelancing-Readiness-in-Marginalized-Group)

machine learning system that identifies digital skill gaps among underprivileged communities and recommends personalized upskilling paths to help them access freelance opportunities. built during my work at zuup to bridge the digital divide with ai-driven guidance aligned to real-world market demands.

**the problem:** millions of learners from underserved communities want to participate in the freelance economy but lack clarity on which digital skills are in demand or worth learning next.

**the solution:** this project simulates user personas, analyzes freelance job data from multiple sources, and outputs personalized skill recommendations based on current market needs, learning effort, and career impact.

**methodology:**
- persona simulation: creates realistic user profiles with predefined socio-economic and skill backgrounds
- skill matching: uses jaccard similarity to compute match between user skills and job requirements
- recommendation engine: suggests top skills based on relevance, frequency, and learning effort
- visualization: built in streamlit to show fit scores, skill gaps, and estimated learning time interactively

**datasets used:**
- upwork job postings dataset (2024)
- freelancer data analysis jobs
- skill & career recommendation dataset
- lloyds consumer digital index (2022)
- ons uk unemployment dataset (2021)

**published research:** [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.16150774.svg)](https://doi.org/10.22214/ijraset.2025.73265)

**tech stack:**

- skill-job match scoring and personalized learning roadmap
- interactive dashboard visualizing impact of skill recommendations
- specifically targeted for marginalized learners, especially women and school dropouts

**impact:** targeting communities with limited access to career guidance, providing data-driven pathways to digital employment
